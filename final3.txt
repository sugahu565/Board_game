@startuml
title final3 — последовательность хода через GUI
!theme plain

actor Игрок
participant DesktopWindow
participant DesktopGameController
participant Game
participant Round
participant CardEffectHandler
participant GameRepository
database SQLite

Игрок -> DesktopWindow : вводит имя
DesktopWindow -> DesktopGameController : addPlayer(name)
DesktopGameController -> GameRepository : registerPlayer(name), если имя новое
GameRepository -> SQLite : сохранить профиль
DesktopWindow -> DesktopWindow : renderLobby()

Игрок -> DesktopWindow : начинает партию
DesktopWindow -> DesktopGameController : startGame()
DesktopGameController -> Game : создать Game(players)
Game -> Round : создать раунд и раздать карты

Игрок -> DesktopWindow : открывает руку и выбирает карту
DesktopWindow -> DesktopGameController : revealHand(), submitMove(...)
DesktopGameController -> Game : processGameMove(Move)
Game -> Round : checkMove(move)
Game -> CardEffectHandler : validate(move), apply(move)
Game -> Round : recordMove(move)
Game --> DesktopGameController : результат хода

alt партия завершена
    DesktopGameController -> Game : getResult()
    DesktopGameController -> GameRepository : writeGame(result)
    GameRepository -> SQLite : сохранить партию и ходы
    DesktopGameController -> GameRepository : getHistory(), getStats()
end

DesktopGameController --> DesktopWindow : обновлённое состояние
DesktopWindow -> DesktopWindow : render()
